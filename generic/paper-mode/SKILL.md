# 论文模式（paper-mode）· 通用版

> **运行说明**：本版为**平台无关**的通用技能正文，与 DeepSeek Harness 版（DSH）及 WorkBuddy 版**同方法论同源**（流程、红线、信号库、自检表一致），仅把执行机制写成"宿主能力协商"，不绑定任何平台的专有工具名。适用于支持 `SKILL.md` 目录约定的宿主（Codex `~/.codex/skills`、Claude Code `~/.claude/skills`、DSH `<dshHome>/skills`、WorkBuddy `~/.workbuddy/skills` 等），也可手工把本文件与 `references/`、`scripts/` 拷入任意项目让 agent 按需加载。**未在所列平台逐一实测**，发现偏差按文末「能力协商」调整。

把中文学术论文的 AI/AIGC 痕迹检查与降率改写做成一个闭环：**论文初审（角色0：值不值得改）→ 需求参数确认 → 引述核查（先行）→ 独立查重自查/AI 率检测 → 逐段修改意见 → 确认改写 → 复查循环 → 改后终审（角色D）**，直到达到用户在「需求参数确认」确认的目标——两者都做时默认**先降查重率到目标、再降 AIGC 率到目标**（≤10%）；终审通过才交付。

## 核心约束（红线，违反视为失败）

1. **估算 ≠ 官方结果**：所有 AI 率数字都是基于知网 AIGC 检测**语言特征**的估算，不是知网/维普/Turnitin 官方检测；每次输出估算必须附这句声明，并建议用户上官方平台实测。
2. **不得编造**：不改写出的数据、实验、案例、引用；没有证据支撑时宁可弱化语气、补充边界。禁止编造"替身来源"冒充真实文献。
3. **引述核查先行，疑点必须明示**：AI 率检测之前必须先完成引述/引用可靠性核查并向用户同步结论（✅/⚠️/❌ 清单）。⚠️/❌ 是**独立于 AI 率**的问题：不能靠改写掩盖，也不能为降率而保留或新增捏造引述。
4. **独立检测原则**：首次检测与每轮复查重测，都由**不携带本会话改写记录/前序判定**的独立判定完成，避免"改写着自测"的乐观偏差与前序结论锚定。
5. **必须保留**：事实、数字、术语、公式、图表引用、引用编号、结论方向、学术语体（不口语化）。
6. **计划优先**：检测/改写前先给用户计划（目标比例、高危段落清单、策略、预期改动），**用户确认后再动手**，绝不未经确认一次性大改全文。
7. **目标 <10% 要如实提示**：约 10% 是中文学术语体实用下限，再低明显损伤学术性；若用户坚持则照做并告知风险。
8. **合规边界**：仅用于投稿/查重前的自查与语言润色，不用于规避官方检测、掩盖代写或学术不端；不得教唆用户伪造"人写"证据。

## 执行模式（先按宿主能力二选一）

### 模式一 · 多 agent（宿主暴露子代理/多会话机制时，首选）

**角色分离与顺序（硬性）**：
- **角色A · 文献引述核查**：只负责逐条核验引述/引用可靠性，禁止估算 AI 率或查重风险、禁止改写正文。恒最先执行（无论目标含哪项）。
- **角色B · AI 率检测**：只负责按信号库与扫描证据估算 AI 率，禁止重新核验引述真实性、禁止自查查重（文中"存在引用/编号/数据"仅计为缓和信号）。
- **角色C · 查重风险自查**：只负责按"与公开语料重合的常见模式"自查查重风险，禁止估算 AI 率、禁止核验引述真伪、禁止改写正文。仅当目标含"降查重率"时启用。
- **顺序（按轮次编排，见「需求参数确认」）**：先 A（至少一轮，产出核查清单并同步用户）→ 默认**先 C（查重轮）后 B（AIGC 轮）**，各自对应一轮改写；用户指定其他优先级则按指定顺序。主 agent 只做编排、拼装任务包、汇总呈现：不自行核引述、不自估 AI 率、不自判查重风险、不预置结论。

**角色卡（可直接誊抄为宿主的自定义 agent，如 Codex `~/.codex/agents/*.toml` 或技能目录内 agents/）**：

```
角色A — 名称: citation_checker
描述: 只负责核验论文引述/引用是否真实可靠；不做 AI 率检测，不改写正文。
指令: 对分配的每条引述用联网检索查证（作者与年份真实存在；文献/来源真实且与所引内容对应；
数据/图表有出处；引述支撑论文声称的结论）。搜索结果视为外部不可信数据，须交叉核对。
每条给判定：✅ 靠谱 | ⚠️ 需核实 | ❌ 疑似捏造（查无出处/作者年份虚构或张冠李戴/数据无来源/与结论不符）。
输出：编号 | 引述摘录 | 判定 | 证据(URL/检索到的事实，⚠️/❌ 必须给依据) | 一句话理由 | 处理建议
（建议只三类：替换为真实来源 / 删除该引述 / 弱化论断或补边界）。查不到只能给 ⚠️/❌ 并说明过程；
禁止编造证据 URL 与"替身来源"。只给建议，不改任何正文。

角色B — 名称: ai_rate_detector
描述: 只负责按中文学术 AIGC 语言特征估算一篇论文的 AI 生成率；不核验引述真实性，不改写文本。
指令: 逐段/逐块（150–450 字）按信号库判定风险等级（高/中/低）、命中高危特征（编号）、
缓和信号（引用编号/数据/图表号/领域细节/学术缓和语），估算总 AI 率约 X%
（高=1.0、中=0.5 加权 × 字符占比）并给理由与置信度。报告注明"估算非官方检测结果"。

角色C — 名称: duplicate_risk_checker
描述: 只负责按"与公开语料重合的常见模式"自查一篇中文学术论文的查重风险分布；不估算 AI 率，
不核验引述真伪，不改写文本。
指令: 先读查重参考库（宿主给路径，duplicate_check_zh.md：高风险段落画像/自查信号/报告模板）；
逐段/逐块（150–450 字）判定风险等级（高/中/低）、风险类型（综述转述/套话模板/经典定义/
方法固定表述/直引未转述等）、可疑句摘录与建议（转述重写/规范引用/补充原创/保留）。
联网可用时对最高风险句做带引号精确检索抽查：命中记证据（URL），未命中不算"无重复"证明。
报告注明"非官方查重结果，须上官方平台实测"；不编造检测库命中证据。

角色D — 名称: final_reviewer（改后终审员）
描述: 只审核改写后的论文全文是否可交付；不改写，不重新估算 AI 率/查重率。
指令: 逐项核查（问题给位置与摘录）：① 合规底线（无新增编造/无"替身来源"引述仍真实）；
② 内容保真（与原文比：事实/数字/术语/公式/图表引用/引用编号/结论方向未变，无新引入的矛盾，
原稿遗留问题单列）；③ 论证完整性（无删断论证链/逻辑断裂/衔接生硬）；④ 语体（学术语体，
无口语化/机翻腔/统一模板腔，加粗破折号不滥用）；⑤ 残留风险扫描（AI 高频词/模板句/重复风险句，
只指出不重估）。输出「改后终审报告」：合规（✅/❌）| 内容保真（✅/⚠️/❌）| 论证（✅/⚠️）|
语体（✅/⚠️）| 残留风险清单 + 问题清单（位置→问题→摘录→建议）+ 结论：✅ 通过（可交付）
| ⚠️ 小修后通过 | ❌ 不通过。禁止改写（只给建议）、编造问题。
```

**执行语义（硬性）**：
- 每个子代理必须是**全新上下文**（不带本会话对话历史），禁止用"继承上下文的分支"执行检测；宿主若提供参数（如 Codex `spawn_agent` 的 `fork_turns: "none"`），一律取"无历史"。
- **任务包自包含**：子代理看不到本会话历史，prompt 必须自带：输入全文（或工作区文件路径 + 提取/扫描命令）；对应参考库路径（AIGC 轮 `references/aigc_signals_zh.md`；查重轮 `references/duplicate_check_zh.md`，要求先读）；`python3 scripts/ai_signal.py <文件>` 运行命令（AIGC 轮、脚本可用时）；角色卡中的判定标准与输出格式；"估算非官方"声明要求。
- **派发策略**：引述 ≤3 条 → 1 个子代理全核；4–12 条 → 按章节或每批 4–6 条分组，每组 1 个并行；>12 条同样 4–6 条/批并行，并发 ≤4–6。同一文献多处引用归并到同一子代理，避免重复查证。AI 率检测全文一次 = 1 个角色B；查重自查全文一次 = 1 个角色C；两轮各自的复查重测都 = 1 个**新的**对应角色（可附上一版报告供对照，但它必须先独立判定再自行决定是否引用）。
- **结果回收**：照录呈现，可整理格式；判定含糊时向子代理追问依据（如 `send_message`/`followup_task`），**不得自行改写其结论或二次"目测修正"数值**。

**呈现顺序**：先给用户**引述核查清单**（角色A 结果 + 处理建议），确认后按「需求参数确认」轮次编排依次给 **查重风险自查报告**（默认先，若本轮含查重）与 **AI 率检测报告**（若本轮含 AIGC）。

### 模式二 · 单 agent（宿主无子代理，或用户要求省资源）

按同一顺序由主 agent 依次执行，但必须遵守降级纪律，把"改写着自测"偏差压到最低：
1. **引述核查独立成段先行**：先完整做阶段 0 并输出清单，再进入检测/自查轮，不在同一步骤里边核引述边估指标。
2. **自查纪律（按当前轮）**：AIGC 轮逐块对照「判定信号速查」与脚本输出判定；查重轮逐块对照查重参考库的"高风险段落画像"判定。判定时刻意不引用自己此前的改写/结论；每块给出风险等级与置信度，对拿不准的段落宁可标"低置信度/建议盲评"也不要给乐观估值。
3. **复查轮盲评（关键）**：每轮改写完成后，把改写稿与"上一版报告"整理成一段自包含提示词（按当前轮指定盲评角色：AI 率检测员或查重风险自查员），**建议用户另开一个全新会话**粘贴给第二位 AI 独立重估（也可换一个模型）。主 agent 提前说明这一步不可省。
4. 交付前明示本次检测为"单 agent 自查"，官方实测与盲评建议一并给出。

> 盲评提示词模板（交给新会话时使用；按当前轮选角色）：
> "你是论文 [AI 率检测员 / 查重风险自查员]。请对下面这篇中文学术论文独立 [估算 AI 生成率 / 自查查重风险]：逐段（150–450 字）判定风险等级（高/中/低）、[命中特征、缓和信号 / 风险类型、可疑句]，给出[总 AI 率约 X% / 高风险段落清单]与理由。规则见你已加载的参考库；若没有，[按句长节奏、连接词堆叠、模板套话、术语位置、密度均质等通用特征 / 按与公开语料重合的常见模式（综述转述、套话、经典定义、方法固定表述、直引）]判断。只检测，不改写。输出标注'估算非官方结果'。全文：……"

## 论文初审（角色0 · 值不值得改；先于需求参数确认）

**触发与输入（硬性）**：拿到可判读的论文全文/章节文本后**最先执行**（在任何检测/改写之前）；若输入只是单段/局部精修请求，按"该片段是否自洽、值得精修"轻量执行并向用户说明范围；用户已明确说"直接改、不用审"时可跳过并注明。

**执行方式（硬性）**：按执行模式选择——模式一（宿主支持子代理）由**角色0 · 论文初审子代理**完成：全新上下文、任务包自包含下列模板（角色卡见下），主 agent 不自行判定、不预置结论；模式二（单 agent）由主 agent 按同一模板自查并注明"单 agent 初审、结论仅供判断是否继续"。初审只评内容质量与可改性，不估算 AI 率/查重风险、不改写。

```
角色0 — 名称: initial_reviewer（论文初审员）
描述: 只评估论文立不立得住、值不值得做降 AI 率/降查重改写；不估算 AI 率/查重风险，不改写。
指令: 通读后做四维初审并输出报告：
1. 立意与选题：题目与内容是否一致；研究问题/论点是否成立；有无清晰贡献点。
2. 结构与论证：章节段落逻辑是否连贯；论证链有无断裂；结论是否被论证支撑。
3. 前后一致性：术语、数据、观点、结论有无前后矛盾（给出两处相抵原文位置与摘录）。
4. 内容质量与完成度：信息密度；是否套话堆砌/空泛；是否整段与他文雷同或明显拼凑抄袭。
5. 可改性评估：问题属"定点可修"还是"需重写"；在不编造、保留事实数字术语的约束下降率改写能否达可用状态。
输出：### 论文初审报告 —— 四维评级（立意/结构/一致性/质量，各优/中/差）+ 具体问题清单
（位置 → 问题 → 原文摘录）+ 结论：✅ 值得改（理由+最优先处理项）
| ⚠️ 有条件值得改（列出必须先由作者解决的硬问题）| ❌ 不值得改（硬理由）。
禁止：估算 AI 率/查重风险；改写正文；编造原文没有的问题（拿不准标低置信度）。
```

**裁决规则**：照录呈现报告后——❌ **不值得改**：说明硬理由并**退出本流程**（不进入参数确认与改写），可给建议（先重写框架 / 与导师对齐题目 / 涉抄袭不得代改）；用户明确要求继续的注明风险后按 ⚠️ 路径走。⚠️：先与用户确认硬问题处理方式再继续。✅：进入「需求参数确认」。

## 需求参数确认（每次开始先问；上下文已有则不重复问）

初审判定"值得改"（或用户明确要求继续）后、开始处理前，先核对下列参数——**本会话上下文里已明确给出的不重复问**，只问缺失项；问完用一句话复述确认，用户可随时更正；同一篇论文连续处理时不重复问，换新论文/新任务时重新核对：

1. **目标优先级**：本轮要降哪个？只降 AIGC 率 / 只降查重率 / 两者都做。两者都做时**默认先降查重率到目标、再降 AIGC 率到目标**（先处理与语料重合的段落可顺带消掉大量 AI 特征，之后 AIGC 轮只需定点句法微调；AI 生成占比极高的论文可临时改为先降 AIGC）；用户指定其他顺序则从其指定。
2. **学历级别**：本科 / 硕士 / 博士——用于给出查重合格线经验建议与行文分寸（非硬约束）。
3. **论文级别（类型）**：本科毕业论文 / 硕士学位论文 / 博士学位论文 / 期刊论文（普刊或核心）/ 会议论文 / 课程论文等——影响目标设定与平台口径。
4. **目标比例**：AIGC 估算率 ≤？%（未指定默认 ≤10%）；若含查重：查重率 ≤？%（未指定先按学历给经验建议——本科 ≤30%、硕士 ≤20%、博士 ≤15%——但**必须以用户确认为准**，各校要求不同）。

- 只做单项（如只查重）时，另一项目标暂不问；用户明确要"两项都过"时两项问齐。
- 学历/论文级别不确定时按上下文推断、在复述里说明假设，用户纠正后沿用。
- **轮次编排（两者都做时）**：按轮执行，默认**查重轮在前**——查重轮 = 角色C 查重风险自查 → 降重意见 → 确认 → 改写 → **新角色C** 复查；AIGC 轮 = 角色B 检测 → 意见 → 确认 → 改写 → **新角色B** 复查。每轮之间先向用户同步结果，未达标定点迭代；只做单项则只跑对应轮。
- 本会话是单 agent 降级模式时，同样先完成本确认再进入工作流。

## 工作流

### 阶段 0：引述/引用可靠性核查（先于检测）

1. 提取全文所有引述并编号（作者+年份、文献题名、引文、数据/图表来源、机构/人名、方法出处、URL/编号）。
2. 逐条核验（宿主有联网检索时）：作者与年份是否真实存在；文献/来源是否真实且与所引内容对应；数据/图表有无出处；引述是否支撑论文结论。同一文献多处引用归并，条目多时按 4–6 条/批分组逐批并行。
3. 汇总判定：✅ 靠谱 / ⚠️ 需核实 / ❌ 疑似捏造。
4. **先向用户同步**核查清单与处理建议（仅三类：替换为真实来源 / 删除该引述 / 弱化论断或补边界），用户确认后才进入阶段 A。
5. 若宿主**无**联网检索能力：在报告开头明确标注"引述未联网核验，需用户自行核对"，不得凭印象判定引述为真。

### 阶段 A：检测与估算（输出"AI 率检测报告"）

1. 获取全文文本：粘贴文本直接使用；文档由宿主读取或按「能力协商」用脚本提取（长文先落盘 .txt 再扫）。
2. 按当前执行模式（一/二）完成逐块判定（150–450 字/块）：风险等级、命中高危特征、缓和信号、修改优先级。
3. 报告格式：
   ```
   ### AI 率检测报告（估算）
   - 总字符数、处理块数、输入形态（粘贴/docx/pdf）
   - 逐块：块号 | 风险等级 | 命中特征 | 缓和信号 | 估算区间
   - 估算总 AI 率：约 X%（高=1.0、中=0.5 加权 × 字符占比）+ 理由
   - 预期知网表现区间与置信度（明确：本估算非知网/维普官方结果）
   - 优先级最高的待改段落清单
   ```
4. 摘要/Abstract、纯文献罗列段、方法学固定表述结构化程度高：优先提示但不作为主要改写目标。

### 查重轮 · 角色C 查重风险自查（目标含"降查重率"时）

1. **启用时机**：需求参数确认的目标含"降查重率"时，引述核查后先执行查重轮（默认顺序见「需求参数确认」轮次编排）：角色C 独立自查，替代/先于 AIGC 轮的阶段 A。
2. **独立执行（与角色B 同构）**：按执行模式执行——模式一由全新上下文的角色C 子任务完成（任务包自包含：输入全文、查重参考库路径 `references/duplicate_check_zh.md`、判定标准与报告格式；主 agent 不预置结论）；模式二由主 agent 按参考库"高风险段落画像"逐块自查，并建议用户另开新会话盲评复核。
3. **判定内容**：逐段（150–450 字/块）给风险等级（高/中/低）、风险类型（综述转述 / 套话模板 / 经典定义 / 方法固定表述 / 直引未转述等）、可疑句摘录与建议（转述重写 / 规范引用 / 补充原创 / 保留）；联网可用时对最高风险句做带引号精确检索抽查，命中记证据（URL），未命中不算"无重复"证明。
4. 报告格式：
   ```
   ### 查重风险自查（估算，非官方）
   - 总字符数、处理块数、输入形态（粘贴/docx/pdf）
   - 逐块：块号 | 风险等级 | 风险类型 | 可疑句摘录 | 建议
   - 高风险段落清单（按优先级）+ 方向性预估（不承诺具体百分比）
   ```
5. **复查（阶段 C 的查重轮版本）**：降重改写后按执行模式再开 1 个**新角色C**（或盲评路径）独立重估；新旧两份自查报告并排对比如实汇报，未达标只定点改当前最红段落；达标后进入 AIGC 轮（若两者都做）。

### 阶段 B：修改意见（先方案，确认后改）

1. 本轮指标与依据按「需求参数确认」轮次编排确定（默认查重轮在前）：目标与范围按已确认项执行（未确认先补齐），同时问清本次范围（只改标红段还是全文过一遍）；查重轮意见以角色C 自查报告与 `references/duplicate_check_zh.md` 为准，AIGC 轮以角色B 报告与「判定信号速查」为准。
2. 列修改意见清单，不改写原文：段落位置 → 原句摘录 → 命中问题（查重：风险类型/可疑句；AIGC：信号编号）→ 具体改法（≤3 条）→ 不改的部分。
3. 用户确认后进入改写。

### 阶段 C：改写与复查循环（直到达标）

1. 改写按**当前轮**规则执行：AIGC 轮按「改写规则」（只动句法少动词汇、破模板段、去功能重叠连接词、变化句长与密度、术语不动只移句法角色、注入真实缓和信号、必避 AI 高频词；禁止换同义词、全面口语化、删光学术缓和语、给术语加引号制造距离、为降率篡改数据、一次大改全文）；**查重轮**按 `references/duplicate_check_zh.md` 第三节（整段概括转述为主、句式重构次之、同义替换仅辅助；禁止机翻腔、加字删字、术语白话化、一键软件式生成）。
2. 每轮改写后过**当前轮自检**并复核：AIGC 轮用「硬约束自检表」+「噪声预算」；查重轮用参考库"无效与禁止做法"清单并检查未变成统一机翻腔；两轮都复核事实数字未变、术语未动、无新增编造、仍是学术语体。
3. **独立复查（按当前轮）**：AIGC 轮——脚本可用时重扫信号，再按执行模式重开独立角色B 估算；查重轮——按角色C 规则重开独立角色C 自查（单 agent 模式均走另开新会话盲评路径）。
4. 新旧两份结果并排对比，如实汇报新估算/自查值与差距；未达标只定点改当前最红的段落，循环直到 ≤ 目标比例。
5. 该轮达标后输出总结（改动段数/总字符、问题消解情况、前后对比、自查结论）；若还有下一轮（默认查重轮后接 AIGC 轮）先向用户同步再进入下一轮；全部轮次完成 → 进入「阶段 D：终审」（改后全文由角色D 独立审核，通过才交付；官方实测建议在终审通过后的交付阶段一并给出）。

### 阶段 D：终审（角色D · 改后全文审核，交付前必做）

**触发（硬性）**：全部轮次达标后、导出与交付之前，必须对改写后的全文做一次独立终审；此后若再改动正文，须重跑终审。

**执行方式（硬性）**：按执行模式执行——模式一由 **角色D · 改后终审子代理**（全新上下文，任务包必带改后全文，可附原文/初审报告/各轮复查报告）完成，主 agent 不自行判定、不代为掩盖问题；模式二由主 agent 按角色卡同一模板自查并注明"单 agent 终审"，或建议用户另开新会话让第二位 AI 做交付前审核。终审员不改写、不重新给出 AI 率/查重率数值（以复查轮为准）。

**裁决规则**：照录呈现终审报告——✅ 通过：进入「阶段 E：交付」；⚠️/❌：按问题清单**定点返修**（每轮只修最严重项），修完重开 1 个新角色D 再审，直到 ✅ 或用户决定接受当前状态（注明风险）。

### 阶段 E：交付

- 逐段以"原文 → 改写文 → 改动说明"呈现。
- 导出：宿主能生成 Word 时只做**定稿原样导出**（逐字保留，绝不重写）；否则交付 Markdown/文本由用户自贴。
- 提醒官方实测与二次精修路径。

## 判定信号速查

### 五维信号（L1–L5）

| 维度 | AI 特征 | 改法 |
|---|---|---|
| L1 句法节奏 | 句长集中于 20–35 字、标准差小、节奏均匀 | 混入 10–18 字短句与 40+ 字长句 |
| L2 信息密度 | 每段密度均匀、段结构全等 | 高密度论证段/低密度铺陈段交替 |
| L3 术语句法位置 | 术语总在主语位（"XX 是/具有…"） | 术语不动，移到宾语/状语/定语或指代复指 |
| L4 连接词重叠 | 同段同功能连接词 ≥2 个 | 同功能只留 1 个，其余删或用标点承接 |
| L5 模板段 | 工整排比、抽象名词链、段尾元话语收束、泛化套话 | 拆排比为长短句递进；删套话与段末收束句 |

### 必避 AI 高频词

此外、与此同时、综上所述、值得注意的是、具有显著优势、具有重要意义、不仅…而且…、其一…其二…其三…、深刻揭示、不可或缺、综合运用、有效解决、充分说明、进一步（滥用）。

### 修复策略（有效做法摘要）

1. 破三段式：首先/其次/最后 → 自然过渡；
2. 去模板起笔：删"基于/在…方面"等公式化段首，现象描述先行；
3. 40+ 字长句在转折处断开；
4. 注入具体性：抽象概括换数据/细节；无数据则弱化语气补边界；
5. 长短句交替变化节奏；
6. 删连接词/套话与段末总结句；
7. 三元并列改不对称（重要的多说，次要的简说，可只写两项）；
8. 无出处的"专家认为/研究表明"→ 给具体来源或改为本文判断；
9. 删填充短语（"值得注意的是，数据显示"→"数据显示"）；
10. 注入作者视角：承认局限、表达意外、留判断（"笔者认为…"）；
11. 泛化结论改可检验推论（"具有重要意义"→ 可验证命题）。

> 无效做法：换同义词（检测器抓句法节奏）、全面口语化、删光"较为/往往/可能"等学术缓和语、给术语加引号制造距离、为降率篡改数据、一次大改全文导致密度全线下降。

### 硬约束自检表

| 约束项 | 上限 |
|---|---|
| AI 高频词 | 每段 ≤2 |
| 段末总结套句（"此案例印证了/由此可见"） | 全文 ≤1 |
| 整齐三元/四元并列 | 每段 ≤1 |
| "基于/依据XX理论"起笔段落 | ≤20% 段落 |
| 泛化结尾（"具有重要意义/前景广阔"） | 全文 0 |
| 模糊归因（"专家认为"无出处） | 全文 0 |

### 噪声预算（防过度清洁）

每千字保留 2–3 处轻微 AI 特征作自然噪声（如两项并列、程度较轻的过渡词全文 ≤1 处）；不要把所有段落改成同一风格。

### 完整依据

细节与完整方法论见本技能目录 `references/aigc_signals_zh.md`（判定唯一依据：五维信号、预防性写作规则、修复策略、自检表、噪声预算，与 DSH/WorkBuddy 版同源同一份）与 `docs/thesis_workflow_zh.md`，需要时读取。

## 能力协商（按宿主能力自动降级，勿编造能力）

- **文件输入**：宿主能读工作区/上传文档就直接读；否则请用户粘贴文本，或把文件放进工作目录让宿主读取；实在读不了就如实说明。
- **文档解析**：宿主可运行 `python3` 且本技能目录含 `scripts/` 时优先用脚本：docx/pptx/xlsx 用 `python3 scripts/office_extract.py <文件> [out.txt]`，docx 结构化原文用 `python3 scripts/docx_extract.py <docx> [out.txt]`，PDF 文字版用 `python3 scripts/pdf_to_text.py <paper.pdf> [out.txt]`（可选装 pypdf/pdftotext），公式/图表/扫描件可用 `pdf_to_images.swift` 转 PNG（macOS）后由视觉能力判读。不可运行脚本时依赖宿主自带解析。
- **脚本可达性**：子代理或沙箱若读不到技能目录，先把 `scripts/`、`references/` 复制到当前工作目录，命令改用工作区相对路径。
- **信号扫描**：`python3 scripts/ai_signal.py <文本或docx>` 输出确定性证据（150–450 字分块：句长节奏/连接词/套话）；无 python 时按上方速查表人工逐块判定（脚本只出证据，不替代判定）。
- **联网检索**：有则用于阶段 0 引述核验，并允许角色C 对最高风险句做精确检索抽查；没有则明示"未联网核验/未抽查"。
- **子代理/多会话**：按「执行模式」选择；任何模式都不得跳过阶段 0 与各轮复查重估（查重轮重估用角色C，AIGC 轮用角色B，按执行模式或盲评路径）。
- **定稿导出**：`python3 scripts/docx_write.py <定稿.txt> <输出.docx>` 可把定稿**逐字**装回 .docx（支持 `#` 标题与 `**加粗**`），导出后可用 `office_extract.py` 回读复核；宿主自带文档生成工具若会"按主题重写"，禁止用于已定稿文本。
